# Aakarsh XP

An interactive Windows XP-inspired portfolio for Aakarsh “Chandler” Agarwal.

## Run locally

```bash
npm install
npm run dev
```

## Included desktop applications

- XP Internet Explorer for portfolio links
- Command Prompt with portfolio commands
- Calculator
- Autosaving Notepad
- My Documents
- My Pictures gallery
- Windows Media Player-style music app
- Control Panel
- Tic-Tac-Toe and Snake
- Working Start Menu, taskbar, logoff and shutdown screens
